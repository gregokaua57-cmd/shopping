# Shopping - E-Commerce Platform

Uma plataforma de e-commerce moderna construída com Node.js, Express e React.

## 🚀 Recursos

- ✅ Autenticação de usuários
- ✅ Catálogo de produtos
- ✅ Carrinho de compras
- ✅ Sistema de pagamento (Stripe)
- ✅ Avaliações de produtos
- ✅ Painel administrativo
- ✅ Rastreamento de pedidos

## 📋 Tecnologias

### Backend
- Node.js + Express
- MongoDB
- JWT para autenticação
- Stripe para pagamentos

### Frontend
- React
- Redux/Context API
- Tailwind CSS
- Axios para requisições

## 🛠️ Instalação

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## 📝 Variáveis de Ambiente

Crie arquivos `.env` em `backend/` e `frontend/` com as configurações necessárias.
